# HistData XAUUSD

Free, no-login 1-minute ASCII bars from [HistData.com](https://www.histdata.com/download-free-forex-historical-data/?/ascii/1-minute-bar-quotes/xauusd). Annual zips 2009–2025 and monthly zips for 2026. 2003–2008 did not download (empty response).

Timezone: America/New_York (DST-aware). See the parent `data/raw/README.md`.

Zips are gitignored. The committed research series are the gzip resampled files in this folder.
